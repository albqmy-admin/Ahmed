# ملاحظات مصادر SEO لمكتب البقمي 2

- Google توضّح أن تطبيقات JavaScript تمر بمراحل الزحف والرندر والفهرسة؛ المحتوى المتاح في HTML الأولي أسرع وأسهل على الزاحف، كما أن العرض المسبق مفيد حتى مع دعم Google لـJavaScript. مصدر: https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics
- Google توصي بملف XML sitemap في جذر النطاق مع روابط كاملة مطلقة. إرسال sitemap مجرد تلميح ولا يضمن زيارة الصفحات أو فهرستها. مصدر: https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap
- أهلية نتيجة LocalBusiness الغنية تتطلب اسم النشاط وعنوانًا ماديًا. إلى أن يقدّم المكتب عنوانه، لا يُختلق عنوان ولا يُستخدم ترميز LocalBusiness غير مستوفٍ؛ يمكن وصف المكتب ببيانات Organization. مصدر: https://developers.google.com/search/docs/appearance/structured-data/local-business
- تقرير Sitemaps في Search Console يُظهر نجاح القراءة وأخطاء التحليل؛ اكتشاف عنوان URL لا يضمن فهرسته. مصدر: https://support.google.com/webmasters/answer/7451001?hl=en

حالة الحساب: نُشر الموقع على https://albugmi2.vercel.app. لم يُقدّم رمز تحقق Search Console ولم تُمنح صلاحية لحساب Google، لذا تكون الصفحة جاهزة للزحف وإرسال sitemap، لكن لا تُدّعى إضافة الموقع إلى ملكية Search Console أو ضمان ترتيبه.

- توصي Google بوضع معلومات Organization على الصفحة الرئيسية. لا توجد خصائص مطلوبة، ويُوصى فقط بما ينطبق مثل الاسم، الهاتف، الرابط، والشعار. مصدر: https://developers.google.com/search/docs/appearance/structured-data/organization
- يتحقق Search Console من ملكية الموقع عبر طريقة التحقق التي يختارها المالك؛ رمز HTML tag يجب أن يكون الرمز نفسه الذي أنشأه Google ولا يجوز تخمينه أو استبدال رمز مالك آخر. مصدر: https://support.google.com/webmasters/answer/9008080?hl=en
